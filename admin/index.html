Réglages avancés
Responsable du site : comment créer un jeton ?
  1. Sur GitHub : Settings → Developer settings → Personal access tokens → Fine-grained tokens (lien direct).
  2. Nommez-le d’après la personne (ex : « Admin — Awa Koné ») et choisissez une date d’expiration.
  3. Repository access : « Only select repositories » → uniquement le dépôt du site.
  4. Permissions → Contents : Read and write. Rien d’autre.
  5. Générez le jeton et remettez-le à la personne en main propre (pas sur un groupe). Elle le colle ici une seule fois.
  6. Pour retirer l’accès à quelqu’un : supprimez son jeton sur GitHub. Il ne pourra plus publier.
