Comment obtenir un jeton GitHub ?
  1. Sur GitHub : Settings → Developer settings → Personal access tokens → Fine-grained tokens (lien direct).
  2. Repository access : « Only select repositories » → choisissez le dépôt du site.
  3. Permissions → Contents : Read and write.
  4. Générez, copiez le jeton et collez-le ici. Il reste uniquement sur cet appareil.
